Raid Information

What is a raid?

A raid is the massive and rapid sending of messages through a webhook. The goal is to flood a Discord channel with automated messages.

Nuke Mode

Nuke Mode lets you enter up to 100 webhook URLs and spam all of them simultaneously. Every message goes to every loaded webhook at the configured speed.

Raid speed

Default 400ms between messages (2.5 messages per second). Optimal speed to avoid rate limiting.

Raid tips

Nuke mode has its own ping settings so you can @everyone on all hooks at once. Embed and Flood modes are only available in single-target mode.

01Get the webhook URL from the Discord channel settings.
02Paste the URL in the corresponding field.
03Choose a ping mode: @everyone, @here, or No Ping.
04Pick message type: Normal, Embed, or Flood.
05Write the message. Leave empty for default branded message. Use {n} for message number.
06Configure the number of messages and speed.
07Click "Start Raid" and watch the webhook fill with messages.
08To stop the raid, click "Stop" at any time.
Tip On first send, the webhook is automatically renamed to discord.gg/luascript. Embed lets you set an optional title. Flood mode uses \u3164 blank characters to spam giant invisible blocks. Default speed 400ms avoids rate limiting. Nuke Mode sends plain content to all selected hooks.
